# LinkedIn Project Description – Uber Trip Analysis Dashboard (Power BI)

🚖 Uber Trip Analysis Dashboard | Power BI Business Intelligence Project

Designed and developed an interactive Uber Trip Analysis Dashboard in Microsoft Power BI to analyze booking patterns, revenue generation, trip distance, payment preferences, vehicle performance, and location-based ride demand. The dashboard enables stakeholders to monitor operational KPIs and derive actionable business insights through dynamic visualizations and data-driven decision-making.

Key Features

✅ Interactive KPI Cards displaying:

Total Bookings: 104K+
Total Booking Amount: 1.55M+
Average Booking Amount: 14.98
Total Trip Distance: 348K+ km
Average Trip Distance

✅ Dynamic Measure Selection

Toggle between Total Bookings, Booking Amount, and Trip Distance using dynamic measures.

✅ Payment Analysis

Distribution of revenue across payment methods such as Uber Pay, Cash, Amazon Pay, and Google Pay.

✅ Pickup Hour Insights

Peak ride demand analysis based on booking time and pickup hours.

✅ Location-Based Analytics

Total trips by Location ID.
Top-performing pickup and drop-off locations.
Booking concentration analysis by area.

✅ Vehicle Performance Comparison

Comparative analysis of UberX, Uber Comfort, Uber Black, Uber Green, and UberXL.
Metrics include bookings, revenue, average fare, and trip distance.
